## Reproducir desde backend

Usá SCANNER_MODEL con la ruta absoluta del modelo ya descargado. No copiar un índice legado: carece de metadata verificable.

```sh
SCANNER_MODEL=/ruta/dinov2-small-int8.onnx SCANNER_INDEX_DIR=/tmp/indice-visual \
SCANNER_CARD_IDS=me55c-106,me55-23,me55-92,me55-137,me55-145 \
node --env-file-if-exists=.env scripts/scanner-visual-spike.mjs index 5
SCANNER_MODEL=/ruta/dinov2-small-int8.onnx SCANNER_INDEX_DIR=/tmp/indice-visual \
node scripts/scanner-visual-spike.mjs evaluate ../docs/evaluations/manifest.json
```
