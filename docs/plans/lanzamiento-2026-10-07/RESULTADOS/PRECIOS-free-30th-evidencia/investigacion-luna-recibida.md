# Investigación de precios gratuitos y 30th Celebration

Fecha de consulta: 2026-10-13. Investigación documental pública, sin credenciales ni barrido de catálogo. Los enlaces son fuentes primarias de cada servicio/proyecto; no se interpretan datos visibles como licencia de redistribución.

## Conclusión

La opción inmediata más viable sigue siendo TCGdex: API pública sin clave, precios TCGplayer en USD y Cardmarket en EUR, con actualización documentada horaria para TCGplayer y diaria para Cardmarket. La documentación actual identifica explícitamente que cartas recientes pueden no tener listings; además, el repositorio publicó `v2.48.0: 30th Anniversay sets` el 16-09-2026. Por lo tanto, la explicación histórica «el set aún no está ingerido» quedó obsoleta; la evidencia no alcanza para afirmar que cada carta 30th tenga precio disponible hoy. Los endpoints de carta del API no fueron legibles mediante el visor de páginas usado en esta pesquisa, y no se obtuvo una cotización individual verificable.

TCGCSV ofrece un segundo feed útil de USD: actualización diaria declarada, TCGplayer `marketPrice`, y un grupo TCGplayer de Pokémon Japón `M6a: MEGA Expansion 30th Celebration` (group 24721) aparece en el índice público. No es evidencia de cobertura del set inglés `me55`, y sus archivos JSON individuales no pudieron abrirse en el visor. Es una API/cache de tercero, sin licencia explícita de datos encontrada en sus docs; no asumir que «gratis» autoriza redistribuir precios de TCGplayer.

## Evidencia de 30th

- El release oficial de TCGdex `v2.48.0` se titula “30th Anniversay sets” y fue publicado el 16 de septiembre de 2026: [releases de TCGdex](https://github.com/tcgdex/cards-database/releases). Eso acredita que los sets entraron en la base de cartas; no acredita precio de todos sus listings.
- La API pública tiene set `me55` y el índice de TCGCSV muestra `M6a` japonés, group 24721. El índice TCGCSV declara actualización diaria y muestra su última compilación como 10-10-2026 20:06 UTC: [TCGCSV](https://tcgcsv.com/).
- Los docs actuales de TCGdex dicen que las cartas nuevas pueden carecer de precio hasta que haya actividad/listings de mercado. También advierten fallos de asociación entre printings que pueden duplicar precios: [FAQ de precios TCGdex](https://tcgdex.dev/fr/faq).
- No se pudo confirmar de forma reproducible si una carta concreta de `me55` tiene `pricing` poblado hoy. La causa puntual de ausencia visible en PokéScan requiere distinguir: (a) no hay listing/precio en proveedor, (b) el mapeo local set/carta no alcanza el id correcto, o (c) la caché negativa local todavía no venció. Los documentos públicos solo respaldan (a) como posibilidad general; esta investigación no acredita cuál ocurre en una carta específica.

## Encaje con el contrato actual

El contrato existente `PriceProvider` ya modela `id`, `defaultSource`, `defaultCurrency`, `listSets()`, `getSetDetail()` y `getCardPrices(cardId, setId, localId)`. Una integración de TCGCSV o Scrydex puede preservar los IDs canónicos de PokéScan: resolver el mapeo remoto a partir de set/carta y devolver `RemoteCardPrice[]` con `cardId` local, variante normalizada, valores, `source` y `currency`; no usar el ID remoto del marketplace como PK de cartas. Mantener precios namespaced por `provider`, el proveedor activo único, cola/throttle y cachés actuales. En TCGCSV haría falta una capa de mapeo de productos: grupos → sets, producto → carta y `subTypeName` → variante; no asumir equivalencia unívoca sin fixtures revisados. En Scrydex también hay que mapear sus IDs externos. Si se modifica un DTO/contrato persistido, actualizar el espejo frontend/backend en el mismo cambio. Los imports nuevos del backend ESM llevan `.js`.

Para 30th, un chequeo operativo posterior debería usar solo cartas muestra y una sola consulta por carta pasando por el provider/cola, registrar set ID remoto, `localId`, fuente/moneda, timestamp del propio dato si existe, y distinguir `pricing` ausente de precio cero. No ejecutar backfill general hasta que mapeo y términos estén resueltos.

## Solicitudes acotadas realizadas

Se intentaron abrir tres URLs API de TCGdex (`/sets/me55`, `/sets`, `/sets/me55/1`) y dos endpoints JSON de TCGCSV (`/3/24721/products`, `/3/24721/prices`). El visor no pudo acceder a los cinco endpoints; no se reintentaron ni se usó scraping alternativo. Búsqueda/lectura documental del índice TCGCSV, release de GitHub, docs y términos oficiales sí dio evidencia suficiente para comparar opciones, pero no para afirmar precio presente de una carta exacta.
